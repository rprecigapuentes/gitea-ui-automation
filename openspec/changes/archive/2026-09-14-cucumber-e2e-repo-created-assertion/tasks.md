The title assertion still "passed" because both sides derived from the same wrong value. Fixed to `dataTable.hashes()[0]`, confirmed live via a temporary debug log (added, checked, removed) showing `{ name: 'test-repo', visibility: true }`.
  - The `@cleanup` `After` hook only deleted repositories from `scenarioState.repositories` (the `@project-board`-only field) before deleting the org, never `scenarioState.organization.repositories` (this change's own field) - so every `@e2e` run left its org non-deletable (Gitea 500s deleting an org that still owns a repo), leaking both org and repo. Fixed the hook to also delete `organization.repositories`. Manually deleted 3 orgs+repos left over from pre-fix runs via a throwaway script (run and removed).
